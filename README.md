The current work primarily focuses on the design phase of a CCPS creation process. During this stage, the designer is occupied with defining the main elements of the system and establishing the basic rules governing how these elements will co-exist and communicate with each other, as the main leitmotiv of the CCPS is the ability of distributed elements to collaborate. The goal is to provide a general framework that clearly outlines the main steps that involved in the design process, as well as the necessary tools to support various stages of the design process. The tools developed in the framework of this PhD work are presented here.
